; EntityTypeCatalog.ini

; ScenarioEditor Entity Type catalog.
;
; This file populates the Entity Kind / Domain / Country / Category / Subcategory
; combo-box pickers in the Asset / Entity Editor tab (§7.3). It is a small
; curated subset of the SISO-REF-010 standard - extend as needed.
;
; Loaded at application startup. Missing file or malformed entries are
; non-fatal: an empty catalog means the user can still enter raw numeric
; values, but the picker dropdowns will be empty.
;
; Format:
;   [Kind.<id>]                 Top-level entity kind (1 = Platform, 2 = Munition, etc.)
;     Name=...
;
;   [Domain.<kindId>.<id>]      Domain within a kind (e.g. 1.2 = Platform.Air)
;     Name=...
;
;   [Country.<id>]              SISO-REF-010 country code (225 = USA, 222 = Russia, etc.)
;     Name=...
;
;   [Category.<kindId>.<domainId>.<id>]
;     Name=...                  Category within a (kind, domain) pair
;
;   [Subcategory.<kindId>.<domainId>.<categoryId>.<id>]
;     Name=...                  Subcategory under a category
;
; Numeric IDs match the DIS Entity Type wire fields (§14.5).
; -----------------------------------------------------------------------------
